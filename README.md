# Customer Feedback Classification

## Project Overview
This project focuses on building a machine learning system to classify customer feedback using neural networks and natural language processing.

## Week 3 - Task 1: Neural Network Fundamentals

Topics covered:
- Neural network fundamentals
- Activation functions: ReLU, Sigmoid, and Softmax
- Loss functions: MSE and Cross-Entropy
- Gradient descent and backpropagation
- PyTorch automatic differentiation
- Learning rate experiments
- Dropout, Batch Normalization, and Early Stopping

## Technologies
- Python 3.13
- NumPy
- Matplotlib
- PyTorch

## Project Structure
- `data/` - Dataset files
- `models/` - Saved models
